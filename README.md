# SRM_linear_uncertainty_propagation

Linear uncertainty propagation through the Symmetric Reciprocal Match (SRM) calibration by Ziad Hatab.

This repository implements the SRM VNA calibration algorithm together with a full measurement-uncertainty budget, propagated linearly (first order) via [METAS UncLib](https://www.metas.ch/metas/en/home/fabe/hochfrequenz/unclib.html). Starting from raw one-port and two-port calibration-standard measurements plus a table of uncertainty contributors (VNA noise floor, drift, cable and connector repeatability, standard-definition uncertainty), it solves for the SRM error-box terms and reports S-parameters of a de-embedded DUT together with their propagated 1-sigma uncertainty. Results are validated in [Example_Koax.ipynb](Example_Koax.ipynb) against an independent METAS SOLR calibration/de-embedding of the same coaxial measurements.

## Repository layout

- [u_srm.py](u_srm.py) — `uSRM` class: implementation of the SRM calibration, with a nominal solve (`run`) and an uncertainty-propagating solve (`u_run`) plus `u_apply_cal_unc` to de-embed a DUT with propagated uncertainty.
- [aux_functions.py](aux_functions.py) — helper functions: S/T-parameter conversions, switch-term correction, `.tex` uncertainty-table parsing/interpolation, forward/inverse uncertainty propagation through one-port and two-port error boxes, and covariance extraction/attenuator synthesis.
- [Example_Koax.ipynb](Example_Koax.ipynb) — end-to-end coaxial example: loads raw VNA measurements and uncertainty-contributor tables, runs the SRM calibration with and without uncertainty, de-embeds an attenuator and a mismatch, and plots the result against an independent METAS SOLR reference.
- [CoaxMeas_data/](CoaxMeas_data) — raw VNA measurements of the calibration standards (short/open/match on each port, reciprocal network, DUTs) used by the example notebook.
- [Reference_Standards/](Reference_Standards) — characterized definitions of the calibration standards (short, open, match, mismatch, attenuator).
- [Uncertainty_Contributor_Data/](Uncertainty_Contributor_Data) — `.tex` tables of the individual uncertainty contributors (noise floor, drift, cable, connector, linearity, standard definitions).
- [METAS_SOLR_De_Emb/](METAS_SOLR_De_Emb) — independent METAS SOLR calibration/de-embedding results, used as a reference to sanity-check the SRM output.
- `*.tex`, `Att_*.svg`, `MM_*.svg` — uncertainty-contributor/reference tables and the comparison figures generated by the example notebook.

## Requirements

- Python 3
- [numpy](https://numpy.org/)
- [scikit-rf](https://scikit-rf.org/) (`skrf`)
- [metas_unclib](https://www.metas.ch/metas/en/home/fabe/hochfrequenz/unclib.html)
- [matplotlib](https://matplotlib.org/) (for the example notebook's plots)

## Usage

Open [Example_Koax.ipynb](Example_Koax.ipynb) and run it top to bottom. It walks through:

1. Loading the raw coaxial calibration-standard and DUT measurements from [CoaxMeas_data/](CoaxMeas_data).
2. Building the standard-definition models from [Reference_Standards/](Reference_Standards).
3. Reading the uncertainty contributors from [Uncertainty_Contributor_Data/](Uncertainty_Contributor_Data) and assembling per-measurement covariance matrices.
4. Running `uSRM` once without uncertainty (`run`) to obtain nominal error-box terms, then again with the full covariance budget (`u_run`) to propagate uncertainty through the calibration.
5. De-embedding an attenuator and a mismatch DUT (`u_apply_cal_unc`) and plotting the resulting S-parameter magnitude/phase with 1-sigma bands against the independent METAS SOLR reference in [METAS_SOLR_De_Emb/](METAS_SOLR_De_Emb).
